## Evidence independently checked

Source: S. Wells Williams, *The Middle Kingdom* vol. I (1883), IA `middlekingdomas05willgoog`, 10 preregistered test pages. Read P18 `REPORT.md`, `PREREGISTRATION.json`, `eval_results.json`, `decisions.jsonl`, `queue/items.jsonl`, `queue/mapping_sealed.json`, `gold_seal.json`, `gold_v2_seal.json`, preprocessing manifest, and actual source code. **All 30 public text files** (`gold_v2`, `work/ocr_200`, `corrected`) were independently scored using Unicode NFC, whitespace folding and a fresh Levenshtein implementation.

- P18 corrected text result: **248 → 223 minimum character edits** on **23,082 Unicode codepoints**; CER **1.0744% → 0.9661%** (10.08% relative reduction). Page p637 contains a non-BMP Chinese glyph, so UTF-16 code-unit counts differ by 1 from Python Unicode codepoints: this is **not** a gold-length discrepancy.
- `decisions.jsonl`: 98 decisions, 98 unique IDs: 24 `CONFIRM_FIX`, 74 `KEEP`. Queue includes 49 candidate flags and 49 interleaved comparison items.
- Against the defined punctuation-site census: **23 valid confirmed sites / 49 reviewed flags = 46.9% useful-review yield**; **23/62 = 37.1% site coverage by confirmed corrections**. Raw mechanical flag-to-site alignment is a *different statistic*: **30/49 = 61.2%**, covering **30/62 = 48.4%** of census sites. Do not present 46.9% as ungated detector precision.
- One of 24 confirmed repairs (`1` → `¹` footnote marker) was supported by the scan according to Muse but lies outside the stipulated punctuation-census class, so `false_positives=1` in the score JSON is a **scope exclusion**, not proof that the reviewer introduced an actual error.
- P18 `gold` → `gold_v2` contains **11 character-only** `U+0027` → `U+2019` changes and no other textual changes; independent inspection of the original image glyphs was **not** performed in this review.
- Reported raw-scanned-page OCR silent-empty behavior was 7/10 pages, exit 0, requiring documented background-flattening. Original failure samples and on-page crop evidence remain in the Muse environment; we verified the pipeline code and released hash ledger, not the original full image pixels.
- Time metrics: 283 seconds between the first and last **batch-logged timestamps** is a lower bound, not stopwatch-measured human review time. The 396-second overall queue-to-final-decision interval includes setup/interaction overhead and is not a pure reviewer time metric.
- Random controls: 0/49 flagged as errors in this run; controls are drawn from baseline punctuation sites, not risk-matched to the detector's candidates. Candidate vs control may be inferred by the displayed three-DPI readings even though IDs are mixed. **Do not claim a fully blinded randomized efficacy trial**.

## Release-blocking implementation checks (minimal repairs only)

### R1 — Fail-closed quality gates

- `p14/review_tool.py` `lint` computes a gold-seal mismatch yet only prints `LINT_SEAL_MISMATCH`; it does not return nonzero, so a failed integrity gate can be reported as success.
- `p14/p18/run_pipeline.py` prints any empty OCR outputs at the end, but currently does not exit with an error if any preregistered nonblank page returns an empty text file. With a previously observed 7/10 silent-empty failure, this is high-priority.
- **Acceptance:** corrupt one sealed-gold fixture and inject a zero-byte OCR output in a nonblank page; both must cause nonzero exit, explicit page/status evidence, and no misleading successful score. Blank/plate exception must be explicit and source-verified.

### R2 — Correct and safe review display

- `queue.html` lives at `book/queue/queue.html`, yet the generated `img src` is `queue/crops/Q001.png`; a browser resolves this to `book/queue/queue/crops/`, rather than `book/queue/crops/`. Use the correct relative path and check the crop exists.
- OCR context and tier strings are interpolated into HTML without escaping, so OCR text containing `<`, `&` or HTML markup could be rendered as code or break the page. Escape HTML content; keep image paths local and validated.
- **Acceptance:** independently open a generated queue, confirm all crops resolve and literal unsafe-looking OCR text displays as text; no source-image data has to be public.

### R3 — Apply integrity and auditable review semantics

- `decide` allows `CONFIRM_FIX` without `--corrected`; `apply` silently skips such decisions. `apply` also proceeds if review is incomplete, source OCR has changed, spans overlap or a decision has been duplicated, without a hard failure/explicit override.
- `queue/mapping_sealed.json` is a readable JSON file from the beginning, not an access-controlled/cryptographically sealed object; its display claims should reflect that practical limitation.
- **Acceptance:** reject duplicate/missing IDs, incomplete decisions, conflicting spans and stale source hashes before writing output. `KEEP`/`UNCERTAIN` must never modify source; `CONFIRM_FIX` requires an explicit replacement and provenance; write only to new corrected copies; score normalize-before-edit-distance (P16 erratum).
- Do not claim “strict double blind” for an interface that shows tier disagreement. Describe it accurately as **mixed/ID-concealed comparison items, with potential inference**.

### R4 — Actually reusable and independently runnable release package

- `review_tool.py` hardcodes the ten Williams P18 page numbers; `run_pipeline.py` hardcodes book paths and a local Tesseract installation under `~/tess-local`. This is a reproducible P18 experiment, **not yet a plug-and-play tool for arbitrary books**.
- **Acceptance:** a manifest or `--pages` input controls page selection and paths; dependency/install instructions explicitly include Python, Pillow, NumPy (if flattening), Poppler and Tesseract/eng tessdata. Publish a **tiny license-safe synthetic fixture** demonstrating lint → queue → decide → apply → score in a clean clone. Do not require the unpublished 897-page PDF, local `scans_360/` or `gold_v2/` to run the *smoke test*. Full end-to-end evaluation on real scans can remain opt-in.
- Versioned `v0.2.0` artifact must use a **new release-candidate branch from main** and include only reusable code, tests, docs and tiny fixtures; do **not** blindly merge all 83 P18 research artifacts or any full copyrighted/unspecified image collection.

## Product and metrics positioning

**Allowed claim:** “Review-assisted OCR QA research prototype. Detects some punctuation discrepancies using multiple DPI OCR readings, displays source crops, records human decisions and only applies approved changes to a copy. On a ten-page third-book test, human review reduced CER from 1.0744% to 0.9661%. Site coverage varied markedly across source material (P16 85.2%, P17 87.5%, P18 37.1%), and users must review all suggestions.”

**Not allowed:** “Automatic punctuation correction,” “87% recall” without source qualification, “works for all historical books,” “human review takes 2.9 sec per item,” “fully double-blind controls,” or “the tool has measured human work-time savings.”
